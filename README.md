# CHAPTER & CO. — Signature Collection: The Enchanted Rose (V1)

A responsive interactive wedding invitation demo based on the approved Enchanted Rose mockup.

## Deploy
Upload the *contents* of this folder to the root of a GitHub repository. Under Settings > Pages choose Deploy from a branch, `main`, `/ (root)`. Do not upload the ZIP itself.

## Included
11 sections; rose-under-glass welcome; responsive navigation; licensed/client-replaceable audio placeholder with user-gesture playback; three story chapters; demo gallery/lightbox; local sample video with music pause/resume; ceremony and reception OpenStreetMap views; countdown; attire guide; FAQs; browser-local RSVP demo; scroll animation; decorative particles.

## Before client use
- **All photographs are low-resolution crops of an AI-generated website moodboard, not standalone high-resolution photography.** Replace with real client photos or dedicated original full-resolution images. Some concept crops may include visual artifacts or partial typography.
- `assets/audio/music.mp3` is a bundled demo placeholder, not the client's final licensed track.
- `assets/video/prenup-demo.mp4` is a demonstration video, not a genuine prenup film.
- RSVP saves only to localStorage on the guest's own browser. Connect to a secure backend for real collection.
- Ceremony/reception locations and dates are fictional demonstration data; confirm and replace before deployment.
- Google Fonts and OpenStreetMap require an internet connection.
- Syntax checked; browser/device end-to-end QA not completed.

## Theme
Edit CSS variables at the top of `style.css`; replace photography and content while retaining the 11-section Signature Collection structure.
